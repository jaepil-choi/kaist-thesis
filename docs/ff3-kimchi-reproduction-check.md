# 한국 Fama-French 3팩터 재현과 Kimchi 대조

작성일: 2026-09-14

## 1. 질문

- 6월에 한 번 리밸런싱하고 다음 해 6월까지 그냥 보유(buy-and-hold)하는 것이 원문 Fama-French 방식인가
- 그렇게 계산하면 Kimchi Factor와 같은 값이 나오는가

## 2. 결론

원문 Fama-French 방식은 매년 6월 말에 포트폴리오를 구성하고, 버킷 안에서는 시가총액 가중으로 다음 해 6월까지
보유한다. 보유 중 비중은 가격을 따라 움직이고 원래 비중으로 되돌리지 않는다. 이는 매 기간 직전 시가총액으로
가중하는 것과 같은 포트폴리오이며, 둘은 주식수 변화에서만 다르다. 매 기간 고정 비율로 맞추는 것은 여섯
포트폴리오를 SMB(1/3)와 HML(1/2)로 합치는 단계뿐이다.

Kimchi의 편입 기준에 맞춘 구성(시나리오 3)에서 buy-and-hold(W1)는 Kimchi와 사실상 같은 값을 낸다.

- SMB: 상관 0.9985, 추적오차 연 0.85%
- HML: 상관 0.9942, 추적오차 연 1.62%

6월 비중을 매일 되돌려 유지하는 방식(W3)은 SMB 0.9785, HML 0.9634로 Kimchi 방식이 아니다.

## 3. 계산 조건

**데이터**

- 가격: 보정된 `adjusted_prices.parquet` (§8, `docs/about-data.md` §3.4)
- 유니버스: FGSC 월말 스냅샷
- 재무: `fng_statement_facts`
- 시장·금리: ECOS KOSPI 지수, CD(91일)
- 기간: 2018-07-02~2026-07-20 일별
- 수익률: 가격 파일의 price return (현금배당 제외)

**공통 규칙**

- 매년 6월 실제 마지막 거래일에 구성한다.
- breakpoint는 KOSPI 종목으로 구한다. Size는 중위수, B/M은 30·70 분위다.
- 2×3 포트폴리오를 만든다.
- 다음 종목은 제외한다: SPAC, 구성일 거래정지 종목, 금융업(FGSC.40), KRX 주권이 아닌 종목.
  - 주권이 아닌 종목은 리츠, 선박, 인프라, 투자회사, 외국주권, DR이다(`kimchi-factor-methodology.md` §2.1).
- BE = 자본총계 − 비지배지분이며, BE ≤ 0이면 제외한다.
- RM은 KOSPI 수익률, RF는 CD91을 (1 + y/100)^(1/252) − 1로 환산한 값이다.

**시나리오**

| 시나리오 | B/M 분모 | 재무제표 |
|---|---|---|
| 1 원문 FF | 전년 12월 ME | 연결 |
| 2 Kimchi 맞춤 | 6월 ME | 연결 |
| 3 Kimchi 맞춤 + 별도 대체 | 6월 ME | 연결이 없으면 별도 |

vqapr 결과는 7월 첫 거래일 종가에 매수한다. vqapr는 결정 시점의 종가에 체결할 수 없기 때문이다. 또한 거래정지
또는 상장폐지된 보유 종목의 돈은 새 포트폴리오로 옮기지 못한다. 가중 방식 비교(W1–W3)는 pandas로 계산했으며,
표준 FF 시점에 따라 6월 말 종가로 구성하고 7월 첫 거래일부터 수익률을 셌다.

## 4. 시나리오별 결과 (vqapr 대 Kimchi)

| 시나리오 | SMB 상관 / 추적오차 | HML 상관 / 추적오차 |
|---|---|---|
| 1 원문 FF | 0.966 / 4.05% | 0.870 / 7.39% |
| 2 Kimchi 맞춤 | 0.991 / 2.06% | 0.980 / 2.99% |
| 3 + 별도 대체 | 0.997 / 1.26% | 0.992 / 1.91% |

RMRF는 모든 시나리오에서 상관 1.000이다. 시나리오 1과 2의 차이는 대부분 B/M 분모에서 나온다. 시나리오 3의
버킷 수익률 상관은 S1 0.999, S2 0.998, S3 0.994, B1 0.999, B2 0.995, B3 0.995이다.

## 5. 가중 방식 비교

같은 6월 구성에 버킷 안 가중 방식만 바꿨다. 수치는 Kimchi 대비 상관 / 추적오차(연)이다.

| 방식 | 시나리오 3 SMB | 시나리오 3 HML | 시나리오 2 SMB | 시나리오 2 HML |
|---|---|---|---|---|
| W1 buy-and-hold | **0.9985 / 0.85%** | **0.9942 / 1.62%** | 0.9927 / 1.88% | 0.9823 / 2.81% |
| W2 직전일 시가총액 | 0.9982 / 0.93% | 0.9934 / 1.72% | 0.9924 / 1.92% | 0.9821 / 2.82% |
| W3 6월 비중 고정 | 0.9785 / 3.38% | 0.9634 / 4.03% | 0.9744 / 3.64% | 0.9507 / 4.65% |
| vqapr | 0.9967 / 1.26% | 0.9918 / 1.91% | 0.9912 / 2.06% | 0.9799 / 2.99% |

- W1과 W2는 서로 추적오차 연 0.4–0.6%로 거의 같다. Kimchi가 둘 중 어느 쪽인지는 이 데이터로 가를 수 없고,
  W1이 조금 더 가깝다. Kimchi 원문은 가중을 "VW와 EW를 모두 산출"이라고만 적고 있다.
- W3는 W1 대비 추적오차가 연 3.2–3.7%이고, SMB 평균이 연 +5–6% 어긋난다.
- vqapr는 W1 대비 추적오차가 연 0.9–1.1%이다. 매수 시점이 하루 늦고 매각할 수 없는 보유분의 돈이 묶이기
  때문이다.

## 6. 월간 팩터

Kimchi는 월간 팩터를 일간과 따로 계산한다. 2018-07~2026-06(96개월)을 Kimchi 월간 파일과 대조했다.
월간 버킷 수익률은 일간 버킷 수익률을 달마다 복리로 이은 값이다. buy-and-hold에서는 이 값이 한 달
보유수익률과 같다. 이 월간 버킷에 팩터 공식을 적용했다.

| 구성 · 방식 | SMB 상관 / 추적오차 | HML 상관 / 추적오차 |
|---|---|---|
| 시나리오 3 W1, 월간 버킷 → 팩터 | **0.9993 / 0.78%** | **0.9931 / 1.69%** |
| 시나리오 3 W1, 일간 팩터를 복리로 이음 | 0.9933 / 3.10% | 0.9885 / 2.17% |
| 시나리오 3 W2, 월간 버킷 → 팩터 | 0.9992 / 0.86% | 0.9926 / 1.75% |
| 시나리오 3 W3, 월간 버킷 → 팩터 | 0.9819 / 4.91% | 0.9403 / 4.93% |
| 시나리오 2 W1, 월간 버킷 → 팩터 | 0.9968 / 1.75% | 0.9801 / 2.88% |

- Kimchi 월간은 일간 팩터를 복리로 이은 값이 아니라, 월간 버킷 수익률로 따로 계산한 값이다. 일간 팩터를
  이으면 SMB 평균이 연 +2.4% 어긋나고 추적오차가 네 배가 된다.
- RM은 월말 KOSPI 수준 비율이다. RF는 월말 CD91 연율 y에 (1 + y/100)^(1/12) − 1을 적용한 값이다. 둘 다
  96개월 모두 Kimchi와 차이가 0이고, RMRF도 같다.
- 시나리오 3 W1의 월간 버킷 상관은 0.996–0.9996이다. 평균 수익률은 Kimchi보다 연 0.1–3.0% 낮으며(B3 −3.0%,
  S3 −2.5%) 일간과 같은 수준 차이다.

## 7. 남는 차이

- **수준**: 모든 버킷이 Kimchi보다 연 0.3–3.1% 낮고, 대형주 버킷에서 더 크다. 그 결과 SMB는 연 약 +0.9%,
  HML은 연 약 −2.0% 어긋난다. price return과 total return의 차이로 설명되는 크기지만 배당 자료와 대조하지는 않았다.
- **편입**: 시나리오 3에서도 S3 버킷의 종목 수가 Kimchi보다 6.2% 적다. 2026년 구성분은 전체적으로 10% 적은데,
  FY2025 별도재무제표가 264개사뿐이고 2025-12부터 스냅샷 범위가 바뀌었기 때문이다.
- **재무제표 기준**: Kimchi 원문은 연결재무상태표 항목을 명시한다. 그러나 종목 수는 연결이 없을 때 별도재무제표를
  쓰는 쪽과 맞는다. 규칙은 확정하지 않았다(`kimchi-factor-methodology.md` §7.1).

시나리오 3의 사전 판정 기준은 충족되지 않았다. 팩터 조건 네 가지는 모두 통과했지만 S3 종목 수 차이가
5%를 넘었다. 결과를 본 뒤 기준을 바꾸지 않았다.

## 8. 가격 데이터 보정

A052670 2026-02-09의 1,500:1 병합이 조정되지 않아 수익률이 +29,948%로 기록돼 있었다. 보정 전 시나리오 3의
HML 상관이 0.951까지 떨어진 원인이 이 한 행이다. `scripts/kaist_pilot/correct_adjusted_prices.py`로 이 행과
다른 벤더 조정계수 결함 8행을 고쳤다. 수익률이 바뀐 행은 A052670 하나다(−79.97%).

## 9. 남은 과제

- total return 재구성: 일별 배당락일과 DPS 자료가 필요하다.
- S3 종목 수 −6.2%와 2026년 −10%의 원인 확인
- Kimchi가 연결재무제표가 없을 때 별도재무제표를 쓰는지 제공처 확인
- A065180 2016-06-02 재개일 수익률 기준 결정: 벤더 기준가 대비 −69%인가, 마지막 거래가 대비 +31.5%인가
- 이 수치를 만든 코드와 산출물은 vqapr testbed 안에 있고 git에서 제외된다. 논문 표로 쓰려면 W1 계산을
  replication 코드로 옮겨 재현 경로를 남겨야 한다.
