# Thesis asset snapshot

This directory contains the Git-tracked figure and table snapshot used by
`guijarro-korea-replication.md`. The source artifacts remain under the ignored
`outputs/` tree and are regenerated by the replication CLI.

After rebuilding the numbered reports, refresh this snapshot from the repository
root:

```powershell
uv run --no-sync python guijarro-ordonez-2025-replication/scripts/export_thesis_assets.py
```

`manifest.json` records the source run, classification, source paths, byte sizes,
and SHA-256 hashes. The assets are Korean price-return variants or
specification-derived diagrams; they are not the paper's exact U.S.
CRSP/Compustat replication.
