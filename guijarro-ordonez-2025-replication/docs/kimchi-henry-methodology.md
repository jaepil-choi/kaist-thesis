Fama-French 방법론
공통 원칙
유니버스: KOSPI와 KOSDAQ 보통주를 기본 유니버스로 사용한다. KONEX, 비상장, K-OTC, SPAC 종목, SPAC 존속합병 전 구간은 제외한다. 리츠(부동산투자회사), 선박투자회사, 투자회사(펀드), 사회간접자본투융자회사, 외국주권, 주식예탁증권/증서(DR) 등 KRX 증권그룹이 "주권"이 아닌 종목도 제외한다(예: 중국고섬 KDR). Fama-French 원 방법론의 CRSP shrcd 10/11(자국 설립 회사 보통주만) 원칙과 동일하다.
거래정지 제외: 리밸런싱 시점에 거래정지 상태인 종목은 해당 리밸런싱 구간의 포트폴리오 구성에서 제외한다.
금융업 처리: SMB, HML, RMW, CMA는 금융업을 제외한다. MOM은 가격 기반 팩터라 금융업을 포함한다.
수익률: 배당과 권리락 조정이 반영된 total return 계열을 사용한다.
무위험 수익률: 1995년 이후는 한국 91일 CD 금리(한국은행 ECOS)를 일/월 단위로 환산하여 사용한다. CD 금리 통계가 없는 1994년 이전(1980~1994년)은 정기예금금리로 대체한다.
가중 방식: value-weighted와 equal-weighted를 모두 산출한다.
일간/월간 수익률 차이: 일간 수익률과 월간 수익률은 같은 포트폴리오 구성 원칙을 쓰지만, 서로 독립적으로 산출한다. 월간 수익률은 한 달 보유수익률로 각 버킷을 계산한 뒤 팩터 공식을 적용하고, 일간 수익률은 매 거래일의 버킷 수익률을 계산한 뒤 그날의 평균과 차감으로 팩터를 산출한다. 따라서 일간 수익률을 월간으로 누적한 값과 월간 팩터 수익률은 완전히 같지 않을 수 있다.
리밸런싱: SMB, HML, RMW, CMA는 매년 6월의 실제 마지막 거래일에 리밸런싱하고 다음 해 6월까지 보유한다. MOM은 매월 리밸런싱한다.
재무제표 기준: 6월 리밸런싱 시점에는 리밸런싱 연도의 전년도 회계연도 재무제표를 사용한다.
포트폴리오 분류
Size 분류: KOSPI 종목의 6월말 시가총액 중위수를 기준으로 Small과 Big을 나눈다.
팩터 신호 분류: KOSPI 종목의 30%와 70% 분위 기준으로 Low, Neutral, High를 나눈다.
기준 적용: 위 기준을 KOSPI와 KOSDAQ 전체 유니버스에 적용한다.
2x3 포트폴리오: 각 팩터는 Small 3개 포트폴리오와 Big 3개 포트폴리오를 만든다.
버킷 표기: S1/S2/S3, B1/B2/B3에서 1은 낮은 신호, 3은 높은 신호를 뜻한다.
Quantile 탭: Size 중립화 없이 각 팩터 신호만으로 Q1부터 Q5까지 5분위를 나눈다. 5분위 breakpoint는 KOSPI 종목의 20/40/60/80 분위로 만들고, 같은 기준을 KOSPI와 KOSDAQ 전체 유니버스에 적용한다. 이렇게 하면 KOSDAQ과 초소형주 분포가 기준값을 과하게 흔드는 일을 줄이고, 각 팩터의 버킷을 더 안정적인 시장 기준으로 비교할 수 있다.
Size 두 그룹과 팩터 신호 세 그룹을 교차시켜 6개 포트폴리오를 만든다.

SMB는 각 신호 구간의 Small 평균에서 Big 평균을 차감한다.
HML, RMW, MOM은 높은 신호 포트폴리오 평균에서 낮은 신호 포트폴리오 평균을 차감한다.
CMA는 낮은 투자 증가율이 Conservative이므로 Low 쪽을 long, High 쪽을 short으로 둔다.
재무제표 항목
시가총액(ME): 6월 마지막 거래일의 종가에 상장주식수를 곱한 값이다.
장부자본(BE): 연간 재무제표의 자본총계에서 비지배주주지분을 뺀 값이다(비지배주주지분이 없으면 0으로 둔다). BE가 0 이하인 종목은 제외한다.
자본총계: 연결재무상태표의 자본 총액이다.
비지배주주지분: 연결재무상태표 자본 중 종속회사의 소수 주주에게 귀속되는 자본이다.
EBITDA: 이자비용, 법인세, 감가상각비와 무형자산상각비를 차감하기 전 이익이다.
이자비용: 차입금 등 부채 조달에 대해 지급하는 비용이다.
총자산(AT): 재무상태표의 자산총계다.
기본 계산식
BE = 자본총계 - 비지배주주지분
BM = BE / ME
OPE/BE = (EBITDA - 이자비용) / BE
AG = (전년도 총자산 - 전전년도 총자산) / 전전년도 총자산
MOM 신호 = (t-12 ~ t-2 월수익률의 누적수익률)
팩터별 계산
RM: 전체 투자 가능 시장 포트폴리오 수익률로써, 코스피 수익률을 사용한다.
RF: 한국 91일 CD 금리를 사용한다(1995년 이후). 1994년 이전은 정기예금금리를 사용한다.
RMRF: 시장 포트폴리오 수익률에서 무위험수익률을 차감한 시장 초과수익률이다.
RMRF = RM - RF
SMB: 소형주 포트폴리오 평균 수익률에서 대형주 포트폴리오 평균 수익률을 차감한다. Size 신호는 6월말 시가총액 ME를 사용한다.
SMB = mean(S1, S2, S3) - mean(B1, B2, B3)
HML: 장부가치/시가총액이 높은 가치주 포트폴리오 평균에서 낮은 성장주 포트폴리오 평균을 차감한다.
HML = mean(S3, B3) - mean(S1, B1)
BM = (자본총계 - 비지배주주지분) / 시가총액
MOM: 과거 수익률이 높은 Winner 포트폴리오 평균에서 낮은 Loser 포트폴리오 평균을 차감한다. 직전 1개월 수익률 t-1은 제외한다.
MOM = mean(S3, B3) - mean(S1, B1)
MOM 신호 = product(1 + ret[t-12:t-2]) - 1
RMW: 영업수익성이 높은 Robust 포트폴리오 평균에서 낮은 Weak 포트폴리오 평균을 차감한다.
RMW = mean(S3, B3) - mean(S1, B1)
OPE/BE = (EBITDA - 이자비용) / (자본총계 - 비지배주주지분)
CMA: 총자산 증가율이 낮은 Conservative 포트폴리오 평균에서 높은 Aggressive 포트폴리오 평균을 차감한다.
CMA = mean(S1, B1) - mean(S3, B3)
AG = (전년도 총자산 - 전전년도 총자산) / 전전년도 총자산
